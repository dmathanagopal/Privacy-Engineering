# Results

The graph degree-anonymization script prints the generated graph, original and anonymized degree sequences, minimum cost, k-anonymity check, and Erdős–Gallai graphicality check.

The Adult dataset heuristic prints the selected global hierarchy levels, normalized distortion, precision, and number of k-anonymity violations. The generated `adult_anonymized.csv` is intentionally not committed; regenerate it locally using the instructions in the project README.
