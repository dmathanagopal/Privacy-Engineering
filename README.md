# Privacy Engineering

A collection of hands-on privacy engineering projects exploring techniques for protecting sensitive information while preserving data utility.

## Projects

### 1. Data Anonymization

Explores k-anonymity, data generalization, and privacy-preserving transformations.

**Key concepts:**
- k-Anonymity
- Degree Anonymization
- Dynamic Programming
- Graphicality Testing
- Generalization and Suppression

[Explore Data Anonymization](./data-anonymization/)

### 2. Differential Privacy

Explores privacy-preserving statistical analysis using differential privacy mechanisms.

**Key concepts:**
- Laplace Mechanism
- Exponential Mechanism
- Privacy Parameter (ε)
- Sensitivity and Distortion
- Empirical Privacy Diagnostics

[Explore Differential Privacy](./differential-privacy/)

## Technologies

- Python
- Pandas
- Data Anonymization
- Privacy-Preserving Algorithms

## Dataset

The Differential Privacy project uses the publicly available [UCI Adult Dataset](https://archive.ics.uci.edu/dataset/2/adult).

## Purpose

This repository demonstrates practical implementations and experimentation with privacy engineering concepts, including their assumptions, trade-offs, and limitations.
